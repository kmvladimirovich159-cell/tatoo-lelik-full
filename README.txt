# TATTOO — готовый сайт

## Запуск
1. Откройте папку проекта в Visual Studio Code.
2. Установите расширение Live Server.
3. Нажмите правой кнопкой по index.html -> Open with Live Server.

## Файлы
- index.html — структура сайта
- style.css — дизайн и адаптация
- script.js — модальные окна, галерея, формы и отзывы
- assets/images — ваши фотографии

## Важно
Кнопка записи в этой версии работает как демо и показывает успешную отправку.
Отзывы сохраняются в браузере через localStorage.

Для реальных заявок можно подключить:
- Telegram Bot
- EmailJS
- Formspree
- Firebase / Supabase
- собственный сервер

Перед публикацией замените в index.html:
- Ваш город
- номер телефона
- Instagram / Telegram
- название TATTOO на настоящее название студии, если нужно.
