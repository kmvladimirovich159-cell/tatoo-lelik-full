LELKINO TATOO — сайт с админкой портфолио

ЧТО ЗАГРУЖАТЬ НА ХОСТИНГ
--------------------------------
Загрузи ВСЁ содержимое этой папки в одну папку сайта, сохранив структуру:

index.html
script.js
style.css
style-3d-override.css
admin.php
api.php
config.php
/data/portfolio.json
/data/.htaccess
/uploads/...
/uploads/.htaccess

ВАЖНО
--------------------------------
Сайт теперь требует PHP на хостинге, потому что админка сохраняет фотографии на сервере.
Если хостинг поддерживает PHP 8+, всё должно работать.

КАК ДОБАВЛЯТЬ ФОТО
--------------------------------
1. Открой: https://ТВОЙ-ДОМЕН/admin.php
2. Пароль по умолчанию: Lelkino2026!
3. Выбери одну или несколько фотографий.
4. Выбери категорию.
5. Нажми «ЗАГРУЗИТЬ ФОТО».
6. При необходимости измени название/категорию и нажми «Сохранить».
7. Перетащи карточки мышкой, чтобы изменить порядок.

УДАЛЕНИЕ
--------------------------------
Нажми «Удалить» на карточке. Фото удаляется и из портфолио, и с сервера.

ПАРОЛЬ
--------------------------------
Открой config.php и замени:
const ADMIN_PASSWORD = 'Lelkino2026!';
на свой пароль.

ПРАВА НА ПАПКУ
--------------------------------
Папка uploads и файл data/portfolio.json должны быть доступны PHP для записи.
Обычно права 755 на папку и 644 на файлы подходят, но конкретный хостинг может отличаться.

ВАЖНО ПРО ФОРМУ ЗАПИСИ
--------------------------------
Существующая форма записи в этом варианте по-прежнему работает локально в браузере и НЕ отправляет заявку владельцу сайта.
Админка относится только к управлению портфолио.
